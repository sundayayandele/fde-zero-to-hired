## [FDE_Skills_Matrix_90_Day_Plan.xlsx](FDE_Skills_Matrix_90_Day_Plan.xlsx)

A self-assessment workbook for the forward deployed ML engineer role.

| Tab | What it does |
| --- | --- |
| How to use | Rating scale (1–5), scoring logic and an example row |
| Skills Matrix | 30 skills in 7 clusters with target and weight. Enter your self-rating (now and at day 90) in the yellow cells; gap, priority score and band calculate automatically |
| Cluster Summary | Average rating and total priority per cluster, formula-driven |
| 90-Day Plan | A 13-week fast-track plan built around one portfolio project. Set your start date and update weekly status; progress rolls up |

Use it before you start to pick your entry phase, and again at the end of each phase to see what moved. Targets and weights are calibrated from the October 2026 postings in [docs/market-research.md](../docs/market-research.md); adjust them to the role you are targeting.
