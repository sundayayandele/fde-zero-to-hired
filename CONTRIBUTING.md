# Contributing

Improvements are welcome, especially:

- **New job postings** that change the picture in [docs/market-research.md](docs/market-research.md). Add the company, role, family, signature requirements and a link.
- **Better resources** for a phase. Prefer free, current, widely used material.
- **Worked capstone examples.** Link your public capstone repo in an issue and it may be featured.
- **Corrections** to anything outdated or wrong.

## How

1. Open an issue describing the change, or go straight to a pull request for small fixes.
2. Keep the style: short sentences, concrete numbers, tables for weekly plans.
3. Edit [CURRICULUM.md](CURRICULUM.md), not the generated pages in `phases/`, `capstones/` or `docs/`. Then run `python scripts/build.py` and `python scripts/check_repo.py`.
4. Add a line under `## [Unreleased]` in [CHANGELOG.md](CHANGELOG.md).

AI agents: read [AGENTS.md](AGENTS.md) first.
