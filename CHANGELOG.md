### Repo
- Phase, capstone and docs pages generated from `CURRICULUM.md` by `scripts/build.py`.
- Templates, skills matrix workbook and GitHub issue templates.
- `AGENTS.md`, `CLAUDE.md` and the `fde-maintainer` Claude Code plugin for upkeep.
- GitHub Actions: consistency check on every push; monthly refresh reminder with an external link report.
